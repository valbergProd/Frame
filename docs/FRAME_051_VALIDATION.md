# FRAME 0.5.1 validation (UI refinement, recording feedback, Settings redesign), 2026-10-12

## Changes
- Capture folder browsing (`MainWindow.xaml.cs` `BrowseForFolder`): Windows folder pickers (`OpenFolderDialog`/`IFileDialog` with FOS_PICKFOLDERS) list folders only, which made capture folders look empty. FRAME now opens the standard Explorer file dialog (All files first, plus Videos/Images filters), so files are visible while browsing. "Select this folder" + Open returns the folder being viewed; choosing a file returns its folder. Start = current capture folder (else last browsed, else Videos). Cancel changes nothing; the existing atomic save + write probe + rollback still applies. Used by the home button and Settings → Storage.
- Title bar: the small mark beside "FRAME" is removed (custom WindowChrome title; dragging, caption buttons, maximize/restore unchanged). Taskbar/Alt+Tab use the exe icon (WPF default when `Window.Icon` is unset).
- Main logo: mark 25 → 29 px, wordmark 21 → 24 pt (~15%), block 8 px higher; nav buttons keep their position.
- Branding: `assets/Frame.ico` regenerated from the main-logo geometry in #E5AC52 on transparency at 16/20/24/32/40/48/64/128/256 px (8× supersampled; slightly thicker strokes at small sizes) by `work/make_icon.py`; `assets/frame-mark.svg` is now the same gold mark (was turquoise on dark). Both exes embed it; the tray loads the same .ico (WPF resource) at `SystemInformation.SmallIconSize` instead of drawing its own. No turquoise brand assets remain in active resources (the cyan Region magnifier crosshair is functional, not branding). Old icon kept at `work/Frame-turquoise-old.ico`.
- Recording pulse: halo peak alpha 64 → 108; shared intensity now a smoothstep breath over ~2.6 s (≈30–100%) plus slight noise (was ≈55–100%). Each button follows its own state: Shadow glows only when `engine.Replay` is true and no shadow start/stop is pending; manual only in `RecordingState.Recording`; failures clear both. Lifecycle unchanged (shared 12 Hz timer stops when hidden/minimized/tray; glow snaps to the true state on return).
- Removed "Start to build your history. Save clips before stopping."; the info line collapses when empty (active history and budget notes still show).
- Display options: `QuietExpander` style — 24 px circular ring with a chevron that rotates 180° (0.18 s ease) when open, hover/focus accent ring, muted "Display settings" caption beside the display name, 0.16 s fade-in of the options; keyboard toggle via the ToggleButton. Also used for Advanced settings.
- Settings (`SettingsView.cs`): sections Hotkeys → Recording (frame rate, resolution, bitrate, replay duration + presets, disk budget, audio sources + refresh, cursor/combine) → Storage (capture folder with Change…/Open, recovery files) → General (light, reduce motion, compact controls, cues, volume) → Advanced settings (collapsed: FFmpeg path + Choose + detected/usable status, encoder Automatic or probed list, diagnostics, technical notes) → Apply settings. Label/hint column + control column (max 440 px). Same controls, setting keys and Apply semantics; hotkeys and capture folder still save immediately. "Change hotkey" now opens Settings at the top. Global themed Slider used for volume.

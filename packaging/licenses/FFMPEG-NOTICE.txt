FFmpeg recording tools

FRAME Setup downloads the unmodified Gyan FFmpeg 8.1.2 full Windows x64 build
directly from its publisher and installs ffmpeg.exe and ffprobe.exe in FRAME's
tools folder. No FFmpeg binary is embedded in FRAME Setup or hosted in the
FRAME repository. FRAME runs FFmpeg as a separate process.

Publisher: https://www.gyan.dev/ffmpeg/builds/
Package: https://github.com/GyanD/codexffmpeg/releases/tag/8.1.2
FFmpeg source: https://github.com/FFmpeg/FFmpeg/tree/n8.1.2
License information: https://ffmpeg.org/legal.html

Setup verifies a pinned archive SHA-256 and component hashes, and tests the
recording filter and probe executable before installing FRAME. It reuses an
identical verified private copy on upgrades. It does not change PATH, replace
other FFmpeg installations, or change FRAME settings. An explicit FFmpeg path
chosen in FRAME's Settings still takes precedence over the private tools.

Uninstall removes the FFmpeg files installed by FRAME Setup with the app.
Separately installed FFmpeg copies, settings and saved recordings are kept.
